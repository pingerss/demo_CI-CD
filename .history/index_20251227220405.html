🎯 Mục Đích Dự Án

Dự án được thực hiện nhằm tìm hiểu và thực hành quy trình CI/CD trong phát triển phần mềm hiện đại

🔄

Tích hợp liên tục (CI)

Tự động hợp nhất code từ các developer vào repository chung, phát hiện conflict và lỗi sớm trong quá trình phát triển.

🚀

Triển khai liên tục (CD)

Tự động deploy code lên môi trường production sau khi pass tất cả các bước kiểm tra và phê duyệt.

⚙️

GitHub Actions

Sử dụng GitHub Actions làm công cụ CI/CD, tích hợp trực tiếp với repository, dễ cấu hình và quản lý.

📚

Học tập & Thực hành

Hiểu rõ quy trình DevOps, cách thiết lập pipeline, và áp dụng best practices trong phát triển phần mềm.
